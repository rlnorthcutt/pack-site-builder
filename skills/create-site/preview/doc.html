Getting started

SiteTheme scaffolds documentation and product sites from the Ivy + Lattice CSS libraries and the <dark-mode-toggle> web component. You copy a page template, fill in a theme file, and wire up the toggle — the result is a fast, accessible, themeable static site.

Every page shares the same anatomy: a skip link, a sticky header with the dark-mode toggle, a <main id="content">, and a footer. The theme lives in a single theme.css file.

Installation

Vendor the libraries locally (as this preview does) or reference the CDN. Load order matters: Ivy first, then Lattice, then your theme.

# Vendor the libraries into your project
curl -L -o ivy.full.min.css https://cdn.jsdelivr.net/gh/rlnorthcutt/ivy/dist/ivy.full.min.css
curl -L -o lattice.full.min.css https://cdn.jsdelivr.net/gh/rlnorthcutt/lattice/dist/lattice.full.min.css
curl -L -o dark-mode-toggle.min.js https://cdn.jsdelivr.net/gh/rlnorthcutt/dark-mode-toggle/dist/dark-mode-toggle.min.js

Usage

Add the prepaint script before your CSS links, drop the toggle into the header nav, and load the component at the end of <body>.

<script src="dark-mode-toggle.min.js" defer></script>
<dark-mode-toggle></dark-mode-toggle>

Callouts

Tip: use data-tone="info|success|warn|danger" on callouts to add semantic emphasis.

Heads up: never override applied tokens (like --color-bg) directly — override the -light/-dark variants instead, or dark mode will break.
